*** PROJECT OVERVIEW ***
Zabbix Agent2 external plugin for Windows providing continuous metric aggregation with comprehensive statistics (avg, min, max, median, mode, standard deviation, variance).

ARCHITECTURE:
- Agent2 external plugin: Go wrapper + C++ aggregation engine
- Communication: Named pipes (Windows IPC between Agent2 and plugin process)
- Core engine: cpp_common/collector.cpp (background sampling thread, 1-second interval)
- Platform layer: cpp_common/plugin_common.cpp (Windows API samplers)
- Go wrapper: go_agent2_wrapper/main.go (CGO bindings + Zabbix SDK)
- Build system: build_cpp.ps1 (automated build for all components)

KEY TECHNICAL DETAILS:
- Sampling: Background thread samples metrics every 1 second
- Storage: All samples stored in memory (vector) for statistics computation
- Thread safety: Mutex-protected accumulator (lock only during add/fetch)
- Reset pattern: Each query (fetch) returns JSON and resets accumulator
- Statistics: Computed on-demand during fetch (median via sort, mode via frequency map)
- Memory: ~8 bytes per sample × MaxSamples (default 1000) per metric
- Auto-reset: When MaxSamples reached, accumulator clears automatically

IMPLEMENTED METRICS:
1. aggplugin.test - Connectivity test (returns success string)
2. aggplugin.cpu_load - System CPU load % with statistics
3. aggplugin.memory_usage - Available physical memory (MB) with statistics

STATISTICS COMPUTED:
- avg: arithmetic mean
- min: minimum value
- max: maximum value  
- med: median (50th percentile)
- mod: mode (most frequent rounded value)
- dev: standard deviation
- var: variance
- cnt: sample count

JSON OUTPUT FORMAT:
```json
{
  "metric": "cpu_load",
  "values": {
    "all": {
      "avg": 3.06, "min": 1.95, "max": 4.88,
      "med": 2.91, "mod": 3, "dev": 0.75,
      "var": 0.56, "cnt": 12
    }
  }
}
```

WHY THIS SPECIFIC VERSION IS REQUIRED:
- Old SDK v1.2.1 has CRITICAL BUG in handler_windows.go setConnection()
- Bug: Loop counter never incremented, causing immediate return on first error
- Result: Plugin cannot connect to Agent2 named pipe (3-second timeout)
- Fix: Master branch (Oct 7+) fixes the retry logic
- Module path changed: git.zabbix.com/ap/plugin-support → golang.zabbix.com/sdk

DO NOT USE:
- ❌ SDK v1.2.1 or earlier (broken named pipe handling on Windows)
- ❌ Old module path: git.zabbix.com/ap/plugin-support

CORRECT go.mod:
```
module aggplugin
go 1.21
require golang.zabbix.com/sdk v1.2.2-0.20251007063238-42702926b56d
```

BUILD & DEPLOYMENT:
```powershell
# Initialize environment (sets up Go and GCC paths)
.\init-env.ps1

# Build all components
.\build_cpp.ps1 -Variant agent2

# Stop service before deploying
Stop-Service "Zabbix Agent 2"

# Deploy files (paths may vary - see ai_priv.txt for local config)
Copy-Item build\aggplugin-agent2.exe [ZABBIX_PLUGINS]\ -Force
Copy-Item build\libaggcollector.dll [ZABBIX_PLUGINS]\ -Force

# Start service
Start-Service "Zabbix Agent 2"

# Test metrics
zabbix_get -s 127.0.0.1 -p 10050 -k "aggplugin.test"
```
