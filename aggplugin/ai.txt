=== ARCHITECTURE ===

Components:
- Go Wrapper: go_agent2_wrapper/main.go (Zabbix SDK, CGO bridge, plugin discovery)
- C++ Collector: cpp_common/collector.cpp (background sampling thread, multi-source aggregation)
- Plugin Loader: cpp_common/plugin_loader.cpp (DLL management, multi-source API)
- Plugin API: cpp_common/measurement_plugin_api.h (C interface for custom metrics)
- Example Plugins: cpu_load_plugin.dll, memory_usage_plugin.dll, disk_stats_plugin.dll

Data Flow:
1. Go discovers DLLs → collectDLLMetrics() → plugin.RegisterMetrics()
2. C++ collector samples every 1s → plugin_sample_multi_from_dll() → DLL's plugin_collect()
3. Per-source accumulators track statistics → map<source_id, Accumulator>
4. Zabbix queries → Export() → collector_fetch_and_reset_json() → JSON with aggregate + per-source stats

PLUGIN API (measurement_plugin_api.h):
Required Functions (must be exported by DLL):
- plugin_get_info() → Returns plugin metadata, registers keys
- plugin_init(config) → Initialize with configuration
- plugin_collect(results) → Collect measurements (called every interval)
- plugin_deinit() → Clean up resources

Optional Functions:
- plugin_on_reset(key) → Notification when data consumed
- plugin_aggregate_custom(...) → Custom aggregation logic
- plugin_on_init_complete() → Post-initialization callback

Data Types:
- metric_value_type_t: FLOAT, UINT64, STRING, TEXT, LOG
- collect_status_t: OK, ERROR, NOTSUPPORTED, TIMEOUT
- measurement_value_t: {source_id, value, str_value}
- collection_result_t: {key, status, value_count, values[]}

PLUGIN LIFECYCLE:
1. Discovery: Scan PluginPath pattern (e.g., C:\Zabbix\plugins\*.dll)
2. Loading: LoadLibrary() → GetProcAddress() → Validate functions → plugin_init()
3. Sampling: Continuous loop calls plugin_collect() for each plugin
4. Querying: Fetch aggregated stats → plugin_on_reset() callback
5. Shutdown: plugin_deinit() → FreeLibrary()

MULTI-SOURCE METRICS:
Plugin can return multiple values per key (one per source):
- Example: disk.io.read returns 3 values: {"sda": 123.4, "sdb": 567.8, "sdc": 890.1}
- Zabbix item: aggplugin.disk.io.read[sda,avg,60]
- Cache storage: disk.io.read.sda, disk.io.read.sdb, disk.io.read.sdc

MEMORY MANAGEMENT:
- Plugin allocates: values array, source_id strings, str_value strings
- Framework frees: All plugin-allocated memory after processing
- Pattern: malloc/strdup in plugin, free() in framework
