## Architecture

### Module Pattern (IIFE)
```javascript
var MacroListEditor = (function() {
    var config = { userType, canEdit }
    var state = { hostId, macroId, allMacros, ... }
    
    // 20 functions
    function init() { ... }
    function loadHostList() { ... }
    function loadMacros() { ... }
    // ... etc
    
    return { init, loadHostList, loadMacros, ... }
})();
```

### Two-Way Synchronization
```
Table Edit → editCell() → syncTableToText() → Textarea Update
Textarea Edit → onchange → syncTextToTable() → Table Rebuild
```

### Event Flow
```
User clicks host search button
  → openHostSearchDialog() shows modal
  → handleHostSearch() filters on type
  → Click result → confirmHostSearch() saves
  → loadMacros() fetches macros for host
  → populateMacroSelector() fills dropdown
  
User selects macro from dropdown
  → selectMacro(id) switches context
  → displayMacroEditor() renders editors
  → renderMacroTableEditor() shows table
  → renderBulkTextEditor() shows textarea
  → attachMacroEditorEvents() adds handlers
```
