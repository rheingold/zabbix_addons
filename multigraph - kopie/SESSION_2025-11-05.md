## Key Learnings

1. **Module Registration:** Files alone aren't enough - need UI "Scan directory"
2. **Permissions Critical:** chmod 755 required or subdirs unreadable in container
3. **Module vs Widget:** Same ID causes conflict - changed widget to "multigraphwidget"
4. **API Access:** PowerShell with Bearer token works for module management
5. **CMenu API:** Use `APP::Component()->get('menu.main')` not `CMenu::getInstance()`
6. **Widget Framework:** Fully extensible, perfect for our needs (vs hardcoded graph types)
